# 墨窗 · 用户使用手册与设计文档

**墨窗 (MoWin)** 是一款专为 Windows 打造的轻量、纯净且优雅的本地 Markdown 阅读与编辑器。

本项目深度学习和借鉴了 macOS 原生应用 **墨页 (MoYe)** 的设计哲学与核心机制，并在 Windows 操作系统（Windows 10 / 11）上进行了原生化重构与交互适配。

---

## 功能一览

- **本地写作与阅读**：新建、打开和保存 Markdown 及纯文本文件，多文档独立窗口，支持 **编辑**、**双栏** 和 **阅读** 三种模式。
- **实时排版预览**：支持完整 GFM 规范（标题、加粗、斜体、删除线、引用、链接、代码块、表格、列表、任务列表以及本地/网络图片）。
- **视口双向同步滚动**：在双栏模式中，滑动任意一栏，另一栏即时平滑跟随，视口第一行精准对应同一处内容；亦可一键关闭同步，各自独立查阅。
- **选区快捷操作浮动菜单**：在编辑区选中文字时弹出交互菜单，支持加粗、常规字重（去除强调）、斜体、1–6 级标题转换（及恢复正文），并在选区后快速插入代码块、图片、链接、表格和列表。
- **LaTeX 智能识别与一键转换**：选中 LaTeX 公式时，浮动菜单动态置顶「**转换公式**」，将 `\(...\)`、`\[...\]`、`\begin{align}` 或单个数学命令转化为 Markdown 标准 `$..$` 与 `$$..$$` 公式语法。
- **全离线 MathJax 数学公式**：内置离线版 MathJax 3.2.2，无需联网即可排版分数、根式、积分、极限、多行对齐方程与矩阵，渲染为矢量 SVG 并自适应深浅色外观。
- **文档导航与侧栏**：提供树形标题大纲（点击快速跳转对应章节）与本地文件夹文档树（列出子目录中的所有 Markdown/文本文件）。
- **专业导出与打印**：侧栏一键导出包含内嵌公式 SVG 的单文件离线 HTML；支持打印与存储为 PDF，预置正常（25.4 mm）、较窄（12.7 mm）和极窄（6.35 mm）三档专业打印页边距。
- **Windows 原生体验**：
  - Windows 资源管理器「打开方式」关联，一键设为 `.md` 默认打开应用。
  - 标准 Windows 快捷键体系（Ctrl 组合键与 F3 搜索快捷键）。
  - UTF-8 与 UTF-16 编码自适应无损往返，支持保留 Windows 标准 CRLF 与 LF 换行。
  - 左右两栏各自独立的显示比例调节（50% 到 200%），只改变屏幕字号，缩小后一屏容纳更多内容。
  - 跟随系统、浅色与深色三种外观主题。

## 五分钟上手

1. 启动墨窗，按 `Ctrl+N` 新建文档，输入 `# 我的笔记`。
2. 保持「双栏」模式，输入正文；用鼠标选中文本，点击弹出的浮动菜单中的「加粗」或「变为标题…」。
3. 输入 `$\frac{a}{b}$` 或 `$$\int_0^1 x^2\,dx = \frac{1}{3}$$`，右侧即刻离线显示数学公式。
4. 按 `Ctrl+S` 保存为 `.md` 文件；需要插图时，直接从 Windows 资源管理器把图片拖入编辑区。
5. 浏览长篇文稿时，滑动任意一栏查看双向首行对齐效果；点击侧栏大纲中的标题直接跳转。
6. 分享文稿时，从侧栏点击「导出 HTML…」生成无需任何网络依赖的独立网页，或点击「打印 / 导出 PDF…」生成精美文档。

## 1. 打开应用与文件关联

- **启动运行**：在项目目录下运行 `npm start` 即可启动应用。
- **打开文件**：点击顶部「打开」按钮或按 `Ctrl+O`，支持打开 `.md`、`.markdown`、`.mdown`、`.mkd`、`.mmd` 和 `.txt` 文本文件。
- **多窗口支持**：按 `Ctrl+N` 可新建独立窗口，支持同时编辑多个不同文件。
- **设为默认打开方式**：首次启动或通过「文件 → 默认打开 Markdown 文件…」时，应用可将墨窗注册至 Windows 注册表中，从而在资源管理器中双击 `.md` 即可默认使用墨窗打开。

---

## 2. 编辑、预览与阅读模式

顶部操作栏提供三档视图模式：

- **编辑 (Ctrl+1)**：专注文档源码写作，隐藏预览区。
- **双栏 (Ctrl+2)**：左侧编辑，右侧实时显示排版与公式结果。
- **阅读 (Ctrl+3)**：专注文档浏览，隐藏编辑区，提供最舒适的阅读体验。

**双栏同步滚动与解绑**：
- 双栏模式默认启用双向精准同步滚动：视口首行对准相同行号的内容，杜绝错位。
- 在「视图 → 双栏同步滚动」中取消勾选后，两栏可以互不干扰独立滚动；再次勾选时即刻恢复对准。

---

## 3. 选区快捷浮动菜单与公式转换

在编辑区用鼠标或键盘选中文字，稍作停顿后会在选区旁弹出浮动菜单：

- **加粗**：给选中文本添加 `**`，再次点击可取消。
- **常规字重**：精准移除选中文本周边的 `**` 或 `__`，恢复常规字体。
- **斜体**：切换选中文字的 `*` 斜体。
- **变为标题…**：下拉选择 1 到 6 级标题，或选择「恢复正文」。自动兼容并替换原有 ATX (`#`) 或 Setext (`===`/`---`) 标题。
- **插入操作**：在选区之后插入代码块、本地图片、超链接、标准表格、无序列表和有序列表。

### 将 LaTeX 转为 Markdown 公式
当选中的文本包含 LaTeX 结构（如 `\(\frac{a}{b}\)`、`\[...\]`、`\begin{align}...\end{align}` 或未加符号的数学命令 `\sqrt{x}`）时，浮动菜单首项会自动显示深蓝色的「**转换公式**」，点击后一键转为标准 Markdown `$...$` 或 `$$...$$`，并交由内置 MathJax 本地排版。

---

## 4. 离线数学公式排版

公式由内置的 MathJax 3.2.2 离线排版为矢量 SVG，不加载远程 CDN 脚本，不要求系统安装特定公式字体：

- **行内公式**：`$a^2 + b^2 = c^2$`
- **独立公式块**：
  ```markdown
  $$
  \int_{-\infty}^{+\infty} e^{-x^2}\,dx = \sqrt{\pi}
  $$
  ```
- **多行对齐与矩阵**：
  ```markdown
  $$
  \begin{aligned}
  f(x) &= (x+1)^2 \\
       &= x^2 + 2x + 1
  \end{aligned}
  $$
  ```

## 5. 保存与编码无损支持

- 点击顶部「保存」或按 `Ctrl+S` 进行保存；按 `Ctrl+Shift+S` 另存为新文件。
- 支持读取与保存带有 BOM 或无 BOM 的 **UTF-8**、**UTF-16LE** 及 **UTF-16BE** 文本，并完整保留 Windows 标准 `CRLF (\r\n)` 或 Unix `LF (\n)` 换行符。
- 底部状态栏实时显示：`字符数 · 行数 · 当前行号 · 编码 / 换行格式 · 保存状态`。

---

## 6. 侧栏大纲与文件管理

点击左上角「侧栏」按钮（快捷键 `Ctrl+\`）可以显示或折叠侧栏：

- **大纲**：实时提取文档中的所有 1~6 级标题，按层级缩进展示。点击任意标题，编辑区与预览区同步滚动跳转至对应章节。
- **文件**：点击「选择文件夹…」后，递归扫描所选目录下的所有 Markdown 和文本文件（支持深层子文件夹），点击即可在墨窗中打开。

---

## 7. 导出 PDF 与 HTML

侧栏底部的「导出文档」区域提供离线导出能力：

- **打印 / 导出 PDF (Ctrl+P)**：
  - 提供「正常 (25.4 mm)」「较窄 (12.7 mm)」和「极窄 (6.35 mm)」三档专业页边距选项。
  - 等待公式排版完全完成后自动使能按钮，保存的 PDF 中完整保留矢量公式与排版样式。
- **导出 HTML**：
  - 生成完全自包含的 `.html` 独立网页，内置排版 CSS 与公式 SVG。
  - 导出后的 HTML 文件即使发送给未安装 MathJax 的电脑也可以用任何主流浏览器完美离线查阅。

---

## 8. 本地图片与智能输入

- **智能图片路径**：
  - 将图片拖入编辑区或通过菜单选择图片时，若图片位于当前文档同级或子文件夹下，自动写入相对路径（如 `assets/cover.png`）；位于其他位置时自动写入绝对路径。
  - 若路径中包含空格或括号，自动按规范包裹为 `<path with spaces.png>`。
- **智能列表续写**：
  - 在 `- `、`* `、`+ `、`1. ` 或任务列表 `- [ ] ` 之后回车，自动换行并续写下一项序号。
  - 任务列表新增项默认未完成；在空项上再次回车则直接退出列表。

## 10. 架构与测试

墨窗代码组织遵循清晰的高内聚、低耦合模块化规范：

```
MoWin/
├── src/
│   ├── main/                  # Electron 主进程 (窗口、菜单、I/O、PDF 打印、注册表)
│   │   ├── main.js
│   │   ├── menu.js
│   │   ├── default-app.js
│   │   └── preload.js
│   ├── common/                # 跨平台核心业务逻辑 (不依赖 UI)
│   │   ├── markdown.js        # GFM 解析、行号标记 (data-sourcepos)、HTML 生成
│   │   ├── math-source.js     # 数学公式分词防护与大纲还原
│   │   ├── latex.js           # LaTeX 智能检测与转换引擎
│   │   ├── formatting.js      # 选区强调、ATX/Setext 标题转换、智能续写列表
│   │   └── image-paths.js     # 相对/绝对图片路径计算与空格转义
│   └── renderer/              # 前端界面与交互控制
│       ├── index.html
│       ├── styles/            # 浅色/深色现代化 Windows 原生设计样式
│       └── js/                # 核心控制器 (Editor, ScrollSync, Selection, Sidebar...)
├── vendor/                    # 离线第三方组件
│   └── MathJax/               # 离线 MathJax 3.2.2 (tex-svg-full)
├── test/
│   └── self-tests.js          # 35 项全量自动化回归自检测试
├── 示例.md                    # Windows 快速上手体验文稿
└── package.json
```

### 运行全量自检测试

本项目自带覆盖全部核心功能的自动化测试套件：

```powershell
npm test
```

或使用内置参数启动自检：

```powershell
npx electron . --self-test
```

自检套件完整覆盖大纲行号提取、公式保护与恢复、LaTeX 转换、Setext 标题重构、Emoji 选区保持、图片相对路径及 UTF-8/UTF-16 往返等 35 项核心断言，确保每一次更新都稳定可靠。
